# Computer Notes – GUI Operating System & MS Word

## GUI Operating System – Desktop Management

**1. What are icons? Describe different types of icons.**

Icons are graphical symbols that represent an object on the desktop. They are: System icons, Application icons, Shortcut icons, Folder icons, and File icons.

| Type | Description |
|---|---|
| System Icons | These icons are created by the operating system. They represent important functions and features of your computer. |
| Application Icons | These are the icons that represent an application or a program. They allow you to open these applications. |
| Shortcut Icons | These represent links to files, folders and applications that are not located on the desktop. Deleting these will not delete the file/folder/application; it will just delete the shortcut. |
| Folder Icons | These icons represent the folders that contain files and other folders. |
| File Icons | These are the icons that represent files. |

---

**2. List four features of Windows 10.**

The four features of Windows 10 are:

**(a) Start Menu** – When we click on the Start button on the taskbar, the Start menu appears. This menu displays the Main Menu, the All Applications list, and the Tiles area.

**(b) Microsoft Edge** – Windows 10 comes with a new browser called Microsoft Edge. It comes with features like drag-and-drop, image editing, and efficiency mode.

**(c) Multiple Desktops and Task View** – Windows 10 allows you to open multiple desktops at the same time. You can move some of the windows to a virtual desktop. To view them all together, use the Task View button on the taskbar or press Windows key + Tab. It helps in viewing all related windows together on one desktop.

**(d) Windows Snapping** – Windows 10 allows you to snap up to four windows by dragging and dropping them to different corners. Multiple applications can be opened at the same time. To snap a window, use the Windows key + right/left arrow key.


---

**3. What is a desktop? Write its components.**

The first screen that appears when a computer system boots is called the desktop.

The components of a desktop are: icons, the Start button, the notification area, and the taskbar.

---

**4. Write a short note on the shortcut menu.**

A shortcut menu is a menu that appears on right-click. This right-click can be on an icon or on a blank area of the desktop. This right-click menu is also called a context menu.

---

**5. What is a taskbar? What are the components of a taskbar?**

The taskbar is a horizontal strip at the bottom of the desktop. It shows programs that are currently running on the computer.

Its components are:
1. Start Button
2. Search Bar
3. Quick Launch Bar
4. System Tray
5. Notification Area

## MS Word – Tools and Features

**1. List a few features of Word 2016 and 2019.**

1. You can create, edit, and format text documents.
2. It allows you to save and print documents, and it is compatible with other versions of Word and other software.
3. It provides templates for creating professional and good-quality documents like resumes, letters, reports, etc.
4. The software has features like spell checker, grammar checker, and thesaurus to help users.

---

**2. Write the steps to check the spelling and grammar of a document.**

From the Review tab, click Spelling and Grammar. Take the mouse pointer over the errors and right-click. The context menu will suggest changes to correct these errors.

---

**3. What is the use of paragraph spacing and line spacing?**

Line spacing is the vertical spacing between lines of text in a paragraph. Line spacing is used to improve readability and to fit in more text. The default line spacing is 1.15.

Paragraph spacing is the spacing between paragraphs. It is used to increase or decrease the space between paragraphs. The default paragraph spacing is 8 points after each paragraph.

---

**4. What is a thesaurus? How can we use it?**

Thesaurus is a feature in MS Word that gives a word's meaning and alternative words that can be used in its place.

---

**5. What do you understand by "formatting a document"?**

Changing the style of the letters, the size of the letters, the colour, line spacing, etc., to make the document more attractive and draw the reader's attention is called formatting a document.

---

**6. Write the shortcut key for the following:**

| Description | Shortcut Key |
|---|---|
| a) To start Word application | Windows key + R |
| b) To create a new document | Ctrl + N |
| c) To open a document | Ctrl + O |
| d) To save a document | Ctrl + S |
| e) To close a document | Alt + F4 or Ctrl + W |
| f) To cut | Ctrl + X |
| g) To copy | Ctrl + C |
| h) To paste | Ctrl + V |
| i) To undo | Ctrl + Z |
| j) To redo | Ctrl + Y |

---

**7. How to move (cut) text from one location to another?**

Select the text, then right-click and select the Cut option. Now move the cursor to the new location, right-click again, and select the Paste option.
